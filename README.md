# RuBase

RuBase is a Rust workspace for building a database project. The repository is
currently in its engineering-foundation phase.

## Prerequisites

The required Rust toolchain is pinned in `rust-toolchain.toml` and is installed
automatically by `rustup`.

## Common commands

```bash
cargo xtask check
cargo xtask test
cargo xtask ci
cargo run --package rubase-cli
```

See [CONTRIBUTING.md](CONTRIBUTING.md) and the documents under
[`docs/`](docs/) for repository conventions.
