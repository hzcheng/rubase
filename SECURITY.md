# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest
development version only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/hzcheng/rubase/security/advisories/new)
to contact the maintainers privately.

Include a description, reproduction steps, affected versions, and any known
mitigations. A maintainer should acknowledge the report before disclosing it
publicly.
