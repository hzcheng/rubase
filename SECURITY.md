# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest
development version only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the repository
maintainers privately through the security-reporting channel configured by the
hosting platform.

Include a description, reproduction steps, affected versions, and any known
mitigations. A maintainer should acknowledge the report before disclosing it
publicly.
